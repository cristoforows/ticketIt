# M2 evidence index

Evidence records for [M2 — Application foundations and persistent
owner workflow (#3)](https://github.com/cristoforows/ticketIt/issues/3).

## Ownership

**Only the gate-report slice ([#62](https://github.com/cristoforows/ticketIt/issues/62))
edits this index.** Every other M2 slice adds exactly one new evidence
file to this directory, following [TEMPLATE.md](TEMPLATE.md), and
leaves this file alone. This keeps parallel slices from conflicting
with each other over a shared index file, the same convention M1
established for `docs/evidence/m1/README.md`.
